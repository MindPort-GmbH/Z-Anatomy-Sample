## Project Overview
This repository contains the models, materials, and shaders from the Z-Anatomy public repository and adds its own custom assets and scripts for use in the VIRTOSHA Research project.

### Shader Clipping
The main add-on to the original Z-Anatomy are scripts and shaders that allow clipping of materials for a realistic cutting and drilling visualization.
